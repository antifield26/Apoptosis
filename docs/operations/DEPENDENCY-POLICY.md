# Dependency & Licence Policy

Owner: engineering. Enforced in CI by the `dependency-policy` job
(`.github/workflows/ci.yml`) via `cargo deny` with `deny.toml`.
Binding policy text: `docs/legal/third-party.md` section 2.

## 1. Rules

1. **Permissive licences only.** `deny.toml` `[licenses].allow` lists the accepted
   set (MIT, Apache-2.0, BSD-2/3-Clause, ISC, Zlib, Unicode-3.0, CC0-1.0,
   MPL-2.0). Anything else — in particular any GPL/AGPL/SSPL crate — fails the
   build until an explicit owner + legal decision adds it in a reviewed commit
   (CONVENTIONS.md section 6).
2. **crates.io only.** `[sources]` denies unknown registries and any git
   dependency, so a fork of a copyleft project cannot slip in through a
   `git = "..."` requirement.
3. **No wildcard requirements.** `[bans].wildcards = "deny"`.
4. **Reference implementations are banned by name.** `pumpkin*` and
   `valence_protocol` are listed in `[bans].deny` so a future contributor cannot
   add one as a dependency by accident. They are read-only research inputs under
   `OpenSourceMinecraftServer/` (git-ignored, never committed).
5. **Every adopted crate gets a row.** Adding a dependency requires a row in
   `docs/legal/third-party.md` (name, locked version, licence, purpose, first
   use) in the same change.

## 2. Running the gate locally

```text
cargo install cargo-deny --locked        # once
cargo deny --all-features check licenses bans sources
cargo deny --all-features check advisories   # informational
```

## 3. Current state (2026-09-11)

- The third-party dependency graph in `Cargo.lock` is entirely permissive: the
  only licences present are MIT, Apache-2.0, Unicode-3.0 and Zlib-family. (An exact
  package count is deliberately not quoted here: it moves with every internal crate
  added, and Audit 03 caught two stale figures. The `deny.toml` gate checks the
  licences themselves, which is the property that matters.)
- No git dependencies; `Cargo.toml` requirements are caret-versioned and
  `Cargo.lock` is committed (tracked since the first push; ADR-0001 R-10).
- **Advisories are not enforced yet.** The CI job reports them and always
  passes. Reason: there is no triage process, and hard-failing on an unfixed
  upstream advisory would block unrelated work. This is a known gap, tracked in
  Audit 01 (git history, tag `phase-09-final`); closing it means assigning an owner and a
  response window (still open post-P12).

## 4. Data assets

World data generated by a vanilla server (test fixtures under
`crates/test-support/fixtures/`) is **not** a dependency and not vendored game
content: it is produced by the operator running the official jar, is committed
only in the two small, documented cases (see `docs/legal/third-party.md`
section 6), and carries no Mojang binaries, assets or datapacks.
